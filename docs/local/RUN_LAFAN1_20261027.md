# RTX 4090 LAFAN1 run record

Maintainer: Jianglin Yan · prepared 2026-10-28. This report records the completed run on the separate Ubuntu RTX 4090 host. Runtime logs, data, and checkpoints are intentionally not in this repository.

## Data and configuration

- Dataset: 40 G1-retargeted LAFAN1 CSV motions, 30 fps, about 2.45 hours total; converted to 50 fps NPZ.
- Host: Ubuntu 22.04, one GeForce RTX 4090 with 24 GB VRAM.
- Configuration: paper-style observations (`anchor_obs=false`), seed 0, CUDA device 0, 4096 simulation environments, policy batch 4096, 8-step world-model window, 3-layer 2048-unit world-model MLP, 10 world-model batches of 2048 windows per update, 32-step imagination horizon.
- Budget: `max-hours=3`; the saved configuration used this wall-clock limit.
- Run directory: `logs/lafan1_full_20261027/` on the training host.

## Training outcome

- The run stopped at its three-hour limit after 17,650 iterations (about 1.7 iterations/s; elapsed time 3.01 h).
- Final normalized training return was approximately 0.670.
- The latest checkpoint's world-model 8-step normalized error (`nse8`) was approximately 0.0213.

## Full-clip evaluation

The `ckpt_latest.pt` evaluation covered all 40 clips from their first frames, without action/observation/reset noise or domain randomization.

- Mean normalized return: **0.566862**.
- Step-weighted normalized return: **0.5708685**.
- Failed clips: **6 / 40**.

The paper reports 0.82 on the LAFAN1 comparison after 1.2 hours on one H100. This RTX 4090 run demonstrates that the data, simulator, world-model, policy-training, checkpoint, and evaluation pipeline execute end to end. Its score and failure count do not match the paper target, so this is a partial reproduction rather than a successful numerical reproduction.

## 36-environment visualization

The trained checkpoint was replayed after training in 36 vectorized environments, using fixed clip starts, seed 0, and no noise or domain randomization. This was a visualization run, not concurrent training. A 6×6 montage was encoded as a 12-second, 10-fps, 1920×1080 MP4 from 36 captured 320×180 tiles. The generated video and tiles are excluded; `scripts/media/play_grid36.py` provides the interactive viewer and `scripts/media/make_montage.py` assembles captured tiles.
